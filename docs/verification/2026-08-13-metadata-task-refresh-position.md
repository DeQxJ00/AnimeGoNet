# 元数据任务页后台刷新与滚动位置验收（2026-08-13）

## 问题

`#/tasks/metadata` 每 5 秒轮询一次任务状态。旧实现无论响应是否变化都会替换全部任务卡片；
按钮焦点和展开区 DOM 随之失效，展开内容重新加载时页面高度短暂变化，导致浏览位置跳动。

## 修正

- 后台响应与已渲染数据相同时只更新状态，不重建任务卡片；
- 来源/TMDB 对照或策略时间线展开时，后台轮询不替换当前列表；
- 数据确有变化且允许重绘时，以当前视口内第一张任务卡片作为滚动锚点；
- 使用请求序号丢弃过期响应，避免慢轮询覆盖较新的筛选结果；
- 后台刷新失败时保留当前列表，不用错误占位替换现有内容。

## 验收

- 浏览器在 6180 的真实页面滚动后等待一次轮询，修正前可观察到可见按钮节点全部被替换；
- 修正后的 6180 NativeAOT 页面滚动后等待完整一次轮询，可见按钮节点在轮询前后均为
  `11–18`，节点集合与当前浏览位置保持不变；页面控制台无错误或警告；
- 任务数据变化时仍按 5 秒周期更新；TypeScript/Web 测试 21/21、静态 WebUI 测试
  171/171 通过，win-x64 NativeAOT 发布及真实启动通过。
