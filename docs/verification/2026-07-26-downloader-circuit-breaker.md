# qBittorrent 实例级指数退避与熔断（2026-07-26）

## 行为

- 熔断状态属于命名下载器实例，不在 `bt`、`pt` 间共享。
- 网络、HTTP 超时、I/O 和 qB 认证失败开启等待窗；首次 2 秒，连续半开失败为 4、8、16、32、64 秒，之后封顶 120 秒。
- 等待窗内后台调用在取得实例串行锁后立即抛出稳定 `DownloadClientCircuitOpenException`，不触发网络请求。
- 等待到期后状态为 `half_open`，下一次受串行锁保护的调用负责探测。任一成功 qB 操作复位为 `closed`。
- 调用方主动取消、参数错误和本地未配置实例不计入熔断失败。
- Web/API 显式连接测试使用同一实例锁，但可以绕过等待窗；成功后复位，失败则增加连续失败次数。

## 可观察性

`GET /api/v1/downloaders` 对运行中的实例返回：

- `circuit_state`: `closed`、`open` 或 `half_open`
- `circuit_failure_count`
- `circuit_retry_at_utc`

尚未应用、停用或不存在于当前客户端注册表的私有覆盖返回空状态和零失败。SQLite 继续保存连接/同步的脱敏失败码及最后成功时间；运行期熔断状态不写磁盘。

## 自动验收

- 可控时钟验证 2 秒和 4 秒退避、到期半开、成功复位，以及打开期间不重复执行委托。
- `bt` 打开时 `pt` 仍成功执行，证明实例隔离。
- 显式探测在等待窗内成功并复位。
- 已取消调用不增加失败计数。
- 下载快照同步连续执行两次时，第二次不调用离线 fake qB，并持久化 `qbittorrent_circuit_open`。
- 下载器 API 验证认证失败后显示打开状态，修复 fake 凭据后的显式连接测试无需等待即可复位。
