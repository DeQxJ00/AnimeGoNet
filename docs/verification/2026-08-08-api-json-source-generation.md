# API JSON source-generation closure — 2026-08-08

## Scope

- Keep ASP.NET Core Minimal API request and response serialization analyzable by NativeAOT.
- Fail the regular test suite when a new API DTO or a closed legacy response envelope is not generated by `ApiJsonContext`.
- Do not treat the JIT reflection fallback as evidence that a DTO is safe in a published native executable.

## Automated contract

`ApiJsonSourceGenerationTests` performs two independent inventories:

1. every exported, concrete, closed type in `AnimeGoNet.App.Api` must return non-null metadata from `ApiJsonContext.Default.GetTypeInfo`;
2. every closed API contract reachable from the parameter and return signatures of `ApiEndpoints` must return non-null metadata, including concrete `LegacyApiResponse<T>` shapes.

The first check prevents an unused or newly introduced public DTO from silently escaping the context. The second check covers the generic wrappers that cannot be validated as open generic definitions. Compiler-generated closure classes and ASP.NET framework wrappers are deliberately excluded; their API contract generic arguments are still traversed.
