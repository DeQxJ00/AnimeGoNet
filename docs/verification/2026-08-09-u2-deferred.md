# U2 first-release deferral — 2026-08-09

The project owner explicitly deferred U2 from the first release.

- Mikan remains the only supported first-release input source.
- AnimeGoNet does not seed U2 SourceProfiles and does not choose a default U2
  file or seeding strategy.
- No U2 site login, scraping, Cookie/account storage or site-specific acceptance
  work is added.
- The existing compile-time adapter, unified-ingest fields, route-preview behavior
  and regression fixtures remain in the tree. They preserve the generic source
  architecture and future data compatibility; their presence is not a support
  declaration.
- Restoring U2 to release scope requires a new product decision, including the
  default file strategy and seeding behavior.

This is a scope decision only. It does not delete user data, remove existing
generic API contracts or rewrite historical verification documents that record
tests already performed.
