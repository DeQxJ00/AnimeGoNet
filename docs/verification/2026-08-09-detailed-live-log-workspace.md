# 详细实时日志工作区（2026-08-09）

## 行为

后端继续发送上游兼容的文本帧，服务端脱敏和暂停缓存协议不变。前端新增纯函数解析器，
把规范行拆为 UTC 时间、级别、category、Event ID、消息和异常；不符合格式的兼容行按
`unknown` 保留原文。页面提供级别、关键词、类别、Event ID 组合筛选，单条展开、自动
滚动、长行换行以及复制当前筛选结果。

## 安全与容量

- 服务端暂停缓存仍为每连接最新 1000 条；
- 浏览器内存和 DOM 输入仍截断为最新 500 条；
- parser/filter 不解释 HTML，页面只使用 `textContent`；
- 复制来源只取已经过服务端脱敏的兼容文本，不读取日志文件或内部异常对象。
