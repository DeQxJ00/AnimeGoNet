# OpenAPI contract

AnimeGoNet exposes its generated OpenAPI 3.1 document at:

```text
GET /openapi/v1.json
```

The endpoint is intentionally outside `/api` and remains public when an access key is
configured. It describes the authentication contract without embedding the configured
key. All protected API and WebSocket operations still enforce the normal runtime access
middleware.

## Authentication alternatives

Authentication is split into two independently configured boundaries:

- external plugin/API routes (`/api/plugin/*`, `/api/rss`, `/api/download/manager`,
  exact `POST /api/v1/ingest`) use `web.access_key`. They accept plaintext
  `X-AnimeGo-Access-Key`, or its lowercase SHA-256 through `Access-Key` / `access_key`;
- WebUI management routes and `/websocket` use `web.webui_access_key`. They accept
  plaintext `X-AnimeGo-WebUI-Access-Key`, or its lowercase SHA-256 through
  `WebUI-Access-Key` / `webui_access_key`.

Each boundary is unprotected only when its own configured key is empty. A plugin key
never authorizes WebUI management, and a WebUI key never authorizes plugin/import routes.

Public compatibility endpoints such as `/ping` do not carry a security requirement.
The generated document never includes an actual key, credential, local directory,
listening address, or port.

## Stable generation

The document is generated by the .NET 10 `Microsoft.AspNetCore.OpenApi` implementation,
which supports trimming and NativeAOT. AnimeGoNet adds deterministic operation IDs,
one stable route-family tag per operation, the six security schemes, and fixed document
metadata. Runtime `servers` entries are removed so identical binaries and routes generate
byte-identical JSON regardless of host, port, data directory, or access key.

The OpenAPI endpoint excludes itself from the document. Every non-excluded Minimal API
route is compared against the generated path/method inventory in tests, and all 12
operations from the preserved upstream Swagger snapshot must remain present.

AnimeGoNet does not bundle Swagger UI or another JavaScript documentation runtime. API
clients can consume the JSON directly, and the existing local WebUI remains static
TypeScript/HTML/CSS.

`Microsoft.OpenApi` is centrally pinned to `2.7.5` or later in the 2.x line because older
2.x releases are affected by
[GHSA-v5pm-xwqc-g5wc](https://github.com/advisories/GHSA-v5pm-xwqc-g5wc).
